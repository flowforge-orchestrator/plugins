# Edge-функция

Короткое преобразование между узлами. На вход приходит значение предыдущего порта, на выход — результат функции.

Тот же контракт, что у JavaScript в узле «Код»: выражение, тело с `return` или функция `(input) => …`. Асинхронный код не выполняется.

## Входы

| Поле | Роль |
| --- | --- |
| **source** | static, текст функции |
| **input** | порт |
| **timeoutMs** | static, миллисекунды |

## Выход

- **value**

Пример: `input.left + input.right`.
