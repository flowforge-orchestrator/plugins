# Контейнер

Запускает контейнер, дожидается завершения и удаляет его.

Сети нет, привилегий нет, корневая файловая система только для чтения, `/tmp` — маленький tmpfs. Образ задаётся ссылкой реестра без пробелов. Команда — JSON-массив строк, без оболочки на хосте.

Сайдкар плагина должен видеть сокет Docker.

## Входы

| Поле | Роль |
| --- | --- |
| **image** | static, например `alpine:3.20` |
| **command** | static, JSON-массив, например `["echo","hi"]` |
| **env** | static, объект строковых переменных |
| **timeoutMs** | static, миллисекунды |

## Выходы

- **exitCode**
- **stdout**
- **stderr**
