# Ollama: генерация

Вызывает локальный Ollama API для генерации текста.

## Параметры

- **Системный промпт** — инструкции для модели (роль, стиль, ограничения)
- **Пользовательский промпт** — основной запрос к модели
- **Модель** — имя модели (llama3, gemma3, mistral, qwen2 и т.д.)
- **Base URL** — адрес Ollama (по умолчанию http://localhost:11434)

## Выходы

- **text** — сгенерированный текст
- **raw** — полный raw-ответ
- **model** — использованная модель
- **finishReason** — stop, length и т.д.
- **usage** — promptEvalCount, evalCount, totalDuration
