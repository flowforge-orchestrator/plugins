# Jira: получение списка задач

Получает список задач Jira, назначенных текущему пользователю.

## Параметры

- **Base URL** — адрес Jira (например: https://jira.example.com)
- **Token** — Bearer или API-токен (ref на секрет)
- **Statuses** — фильтр по статусам
- **maxResults** — максимум записей
- **onlyActive** — только активные задачи
- **type** — тип задачи
- **fields** — дополнительные поля

## Выходы

- **issues** — массив задач
- **total** — общее количество
