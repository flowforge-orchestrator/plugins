# CalDAV: создать событие

Создаёт новый VEVENT в календаре.

## Подключение (static)

| Поле | Пример |
| --- | --- |
| **CalDAV URL** | `https://nextcloud.example.com/remote.php/dav` |
| **Логин** | `user@example.com` |
| **Пароль** | app-password (ref) |

## Параметры

| Поле | Пример | Описание |
| --- | --- | --- |
| **URL календаря** | `https://…/calendars/user/personal/` | Опционально; из `listCalendars` |
| **Имя календаря** | `Личный` | Опционально; если URL не задан |
| **Название** | `Созвон с командой` | SUMMARY |
| **Начало** | `2026-06-05T14:00:00+03:00` | ISO-8601 |
| **Конец** | `2026-06-05T15:00:00+03:00` | ISO-8601 |
| **Описание** | `Повестка: релиз` | Опционально |
| **Место** | `Zoom` | Опционально |
| **Весь день** | `true` | Для события на весь день: начало/конец как даты (`2026-06-05` / `2026-06-06`) |

Если календарей несколько и не указаны URL/имя — ошибка.

## Выход

- **status** — `created`
- **eventId** — например `1717584000-xyz@flowforge`
- **eventUrl** — URL для последующих шагов
