# CalDAV: изменить событие

Перезаписывает существующее событие по **eventUrl**. Неизменённые поля берутся из текущего события.

## Подключение (static)

| Поле | Пример |
| --- | --- |
| **CalDAV URL** | `https://nextcloud.example.com/remote.php/dav` |
| **Логин** | `user@example.com` |
| **Пароль** | app-password (ref) |

## Параметры

| Поле | Пример | Описание |
| --- | --- | --- |
| **URL события** | `https://…/personal/abc.ics` | Обязательно |
| **Название** | `Созвон (перенесён)` | Опционально |
| **Начало** | `2026-06-05T16:00:00+03:00` | Опционально |
| **Конец** | `2026-06-05T17:00:00+03:00` | Опционально |
| **Описание** | `Новая повестка` | Опционально |
| **Место** | `Офис` | Опционально |
| **Весь день** | `false` | Опционально |

Нужно указать **хотя бы одно** поле для изменения (кроме подключения и eventUrl).

## Выход

- **status** — `updated`
