# Office: xlsx write

Записывает массив объектов в `.xlsx` файл.

## Параметры

- **Строки** — массив объектов
- **Путь** — относительный путь выходного файла
- **Лист** — имя листа (по умолчанию `Sheet1`)
- **Колонки** — опционально: список колонок через запятую
- **Базовая папка** — базовая директория для безопасного резолва пути

## Выходы

- **path** — полный путь к созданному файлу (если задан путь)
- **rowCount** — число записанных строк
- **base64** — содержимое xlsx в base64: можно подать в write-binary (path + base64) или в email как вложение (attachment: { filename: suggestedFilename, base64 })
- **suggestedFilename** — рекомендуемое имя файла (например report.xlsx)
