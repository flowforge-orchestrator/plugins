# Office: csv read

Читает `.csv` файл и возвращает массив строк в виде объектов.

## Параметры

- **Путь** — путь к csv файлу
- **Разделитель** — символ разделителя (по умолчанию `,`)
- **Кодировка** — кодировка файла (по умолчанию `utf-8`)
- **Базовая папка** — базовая директория для безопасного резолва пути

## Выходы

- **rows** — строки csv
