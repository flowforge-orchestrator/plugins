# Office: csv write

Записывает массив объектов в `.csv`.

## Параметры

- **Строки** — массив объектов
- **Путь** — путь выходного csv файла
- **Разделитель** — символ разделителя (по умолчанию `,`)
- **Кодировка** — кодировка файла (по умолчанию `utf-8`)
- **Базовая папка** — базовая директория для безопасного резолва пути

## Выходы

- **path** — полный путь к созданному файлу
