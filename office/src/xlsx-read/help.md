# Office: xlsx read

Читает `.xlsx` файл и возвращает строки в формате массива объектов.

## Параметры

- **Путь** — относительный путь к файлу `.xlsx`
- **Лист** — имя листа (если пусто, берется первый лист)
- **Базовая папка** — базовая директория для безопасного резолва пути

## Выходы

- **rows** — строки выбранного листа
- **sheetNames** — список листов в файле
