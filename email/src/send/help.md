# Отправка электронной почты

Отправляет письмо через SMTP.

## Параметры

- **Тема** — тема письма
- **Кому** — адрес получателя
- **Текст** — текстовая версия (plain text)
- **Содержимое** — HTML-содержимое письма
- **Вложение: путь** — опционально, путь к файлу во вложении
- **Вложение: имя файла** — опционально, имя файла во вложении
- **Вложение (inline)** — опционально, один файл из readBinary или xlsx: объект `{ filename?, base64 }`
- **Вложения (массив)** — опционально, массив `[{ filename?, base64 }, ...]` для нескольких файлов
- **SMTP хост** — адрес SMTP-сервера
- **SMTP порт** — порт (обычно 587 для TLS, 465 для SSL)
- **SSL/TLS** — использовать защищённое соединение
- **Логин** — опционально, логин для SMTP-авторизации
- **Пароль** — опционально, пароль для SMTP (передаётся как ссылка на секрет, ref)
- **От кого (From)** — адрес отправителя письма (обязательно)

## Выходы

- **result** — статус отправки (Ok или ошибка)
