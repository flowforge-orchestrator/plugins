# Snippet-only compose blocks for **plugin-run-local** skill.

Not runnable from this directory: `build.context` must point at the plugins repository root (where `Dockerfile.plugin` and plugin sources live).

Copy fragments into the host repo's `compose.demo.yml` / `docker-compose.yml`, or set `PLUGIN_BUILD_CONTEXT` to repo root when experimenting.

For **this repository**, use root files: `compose.demo.yml`, `docker-compose.yml`, `compose.env.example`.
