# RAG: инвентарь коллекции

Читает все `RagDoc` коллекции в Neo4j и возвращает `{ docCount, documents: [{ docId, title }] }`. `title` — `headingPath` первого чанка документа; если его нет, пусто.

Пишет `observations.inventory`. Судья сверяет с ним полноту ответа, когда рамка вопроса покрывает всю коллекцию.
