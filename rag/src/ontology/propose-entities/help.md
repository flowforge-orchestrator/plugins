# RAG: предложить типы сущностей

LLM предлагает типы сущностей по чанкам и текущей схеме.

## Зачем

Перед извлечением сущностей схема типов должна появиться из текста, а не быть зашита в код.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Чанки** (`chunks`) | `textarea` | да | да | Чанки |
| **Текущая схема** (`schema`) | `textarea` | да | нет | Текущая схема |
| **ID коллекции** (`collectionId`) | `string` | да | да | ID коллекции |
| **API ключ LLM** (`apiKey`) | `ref` | static | да | API ключ LLM |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Кандидаты типов** (`candidateTypes`) | `textarea` | Кандидаты типов |
| **Совпало со схемой** (`matchedExisting`) | `number` | Совпало со схемой |

## Ошибки

Модель вернула невалидный JSON кандидатов типов.
