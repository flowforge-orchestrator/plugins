# RAG: слить онтологию

Сливает кандидатов с текущей схемой коллекции и сохраняет версию.

## Зачем

Кандидаты онтологии нужно свести в версионированную схему коллекции.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Текущая схема** (`schema`) | `textarea` | да | нет | Текущая схема |
| **Кандидаты типов** (`candidateTypes`) | `textarea` | да | да | Кандидаты типов |
| **Кандидаты связей** (`candidateRelations`) | `textarea` | да | да | Кандидаты связей |
| **ID коллекции** (`collectionId`) | `string` | да | да | ID коллекции |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Схема** (`schema`) | `textarea` | Схема |
| **Дельта** (`delta`) | `textarea` | Дельта |
| **Версия схемы** (`schemaVersion`) | `number` | Версия схемы |
| **Число операций** (`operationCount`) | `number` | Число операций |
