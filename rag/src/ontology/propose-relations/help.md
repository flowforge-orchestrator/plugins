# RAG: предложить типы связей

LLM предлагает типы связей относительно принятых типов сущностей.

## Зачем

Типы связей дополняют схему так же, как типы сущностей — без доменных констант в плагине.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Чанки** (`chunks`) | `textarea` | да | да | Чанки |
| **Кандидаты типов** (`candidateTypes`) | `textarea` | да | да | Кандидаты типов |
| **ID коллекции** (`collectionId`) | `string` | да | да | ID коллекции |
| **API ключ LLM** (`apiKey`) | `ref` | static | да | API ключ LLM |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Кандидаты связей** (`candidateRelations`) | `textarea` | Кандидаты связей |
| **Отброшено domain/range** (`rejectedDomainRange`) | `number` | Отброшено domain/range |

## Ошибки

Модель вернула невалидный JSON кандидатов связей.
