# RAG: гард цикла

Решает только одно: продолжать ли цикл. Ответ проходит насквозь без правок.

`breakLoop = true`, когда:

- вердикт судьи `consistent && sufficient && complete`;
- режим `retrieval` и вердикт `complete`: каждое поле контракта заполнено или сдано ходом;
- вердикт `consistent = false` — конфликт значений терминален, модель не должна его сглаживать;
- рамка вопроса `skipRetrieval` — сообщение вне корпуса;
- внешний `turnLimited` или число ходов прогона достигло `maxTurns`.

Пока у `retrieval` есть незакрытое поле, `continueLoop = true`. Следующий ход читает `verdict.gaps` и либо запрашивает поле, либо сдаёт его. Порт `reason` называет причину решения.
