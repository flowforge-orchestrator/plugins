# RAG: claims из предложений

Claim строится из предложения, чей фрагмент лежит внутри названной записи evidence. Хиты поиска и схема сами по себе claim не становятся.

## Зачем

Claim появляется только если фрагмент лежит внутри названной записи evidence.

## Поведение

Предложение без фрагмента внутри названной записи не становится claim. Хиты поиска и schema-строки сами по себе claim не дают. Сравнение фрагмента со записью свертывает пробелы и переносы строк.
