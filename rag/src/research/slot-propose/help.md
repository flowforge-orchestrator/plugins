# RAG: значения полей

Для каждого открытого поля модель копирует один фрагмент из одной записи evidence или оставляет поле пустым. Поле не сдаёт, цикл не закрывает.

## Зачем

Значение поля — дословный фрагмент записи, а не пересказ и не id чанка.

## Поведение

Модель получает короткие id полей и записей (`f1`, `r1`, …); код маппит их обратно на имена слотов и evidence id. Неизвестный id отбрасывается. Propose не сдаёт поле и не закрывает цикл.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Вопрос** (`message`) | `textarea` | да | да | Вопрос |
| **Observations** (`observations`) | `textarea` | да | нет | Observations |
| **API ключ LLM** (`apiKey`) | `ref` | static | нет | API ключ LLM |
| **LLM model** (`llmModel`) | `string` | static | нет | LLM model |
| **LLM base URL** (`llmBaseUrl`) | `string` | static | нет | LLM base URL |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Observations** (`observations`) | `textarea` | Observations |

## Ошибки

При ошибке LLM предложения не добавляются; поле остаётся открытым.
