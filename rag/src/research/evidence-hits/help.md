# RAG: evidence из поиска

Превращает хиты поиска в observation evidence. Домен коллекции здесь заканчивается.

## Зачем

После поиска домен коллекции заканчивается: дальше работают только observation evidence.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Hits** (`hits`) | `textarea` | да | нет | Hits |
| **Source** (`source`) | `string` | static | нет | Source |
| **Поле** (`field`) | `string` | да | нет | Поле контракта, для которого выполнен этот запрос |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Evidence** (`evidence`) | `textarea` | Evidence |
