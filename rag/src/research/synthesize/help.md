# RAG: синтез ответа

Пишет ответ только из поддержанных claims, гипотез и ограничений. Исходный корпус в промпт не входит.

## Зачем

Финальный текст строится из принятых claims и ограничений, без сырого корпуса в промпте.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Вопрос** (`message`) | `textarea` | да | да | Вопрос |
| **Observations** (`observations`) | `textarea` | да | нет | Observations |
| **API ключ LLM** (`apiKey`) | `ref` | static | нет | API ключ LLM |
| **LLM model** (`llmModel`) | `string` | static | нет | LLM model |
| **LLM base URL** (`llmBaseUrl`) | `string` | static | нет | LLM base URL |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Ответ** (`answer`) | `textarea` | Ответ |

## Ошибки

При ошибке LLM ответ может остаться пустым или прежним черновиком.
