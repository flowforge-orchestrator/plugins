# RAG: найти evidence

Чтение S0 evidence по запросу. Если порт **Evidence** пуст — записи берутся из FileKnowledgeStore коллекции.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **ID коллекции** (`collectionId`) | `string` | да | да | Коллекция |
| **Evidence** (`evidence`) | `textarea` | да | нет | Записи; пусто → стор |
| **Запрос** (`query`) | `string` | да | нет | Подстрока текста/источника |
| **Окно** (`timeWindow`) | `textarea` | да | нет | `{ from, to }` |
| **Лимит** (`limit`) | `number` | static | нет | Максимум |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Записи** (`records`) | `textarea` | Evidence[] |
