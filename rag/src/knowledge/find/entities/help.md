# RAG: найти сущности

Чтение S2 entities по запросу.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **ID коллекции** (`collectionId`) | `string` | да | да | Коллекция |
| **Сущности** (`entities`) | `textarea` | да | да | Записи |
| **Запрос** (`query`) | `string` | да | нет | Подстрока label/alias |
| **Лимит** (`limit`) | `number` | static | нет | Максимум |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Записи** (`records`) | `textarea` | Entity[] |
