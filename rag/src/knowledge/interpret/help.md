# RAG: интерпретировать наблюдения

Вход: Evidence и чанки. Выход: пакет наблюдений S1. Проверка «span внутри текста» выполняется внутри шага.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Evidence** (`evidence`) | `textarea` | да | да | Evidence S0 |
| **Чанки** (`chunks`) | `textarea` | да | да | Чанки с evidenceId |
| **Сырые кандидаты** (`raw`) | `textarea` | да | нет | Выход модели (S1-кандидаты) |
| **Фрагмент схемы** (`schemaFragment`) | `textarea` | static | нет | Подсказка схемы для модели |
| **Модель** (`model`) | `string` | static | нет | Имя модели |
| **Лимит кандидатов** (`candidateLimit`) | `number` | static | нет | Максимум кандидатов на тип |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Наблюдения** (`observations`) | `textarea` | ObservationBundle S1 |
