# RAG: зафиксировать evidence

Принимает сырой текст и идентичность документа; отдаёт Evidence (S0) и флаг duplicate. Повтор хеша не создаёт второе свидетельство. Новые записи пишутся в durable store под `RAG_DATA_DIR` (`evidence.json` коллекции).

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Текст** (`text`) | `textarea` | да | да | Сырой текст |
| **ID документа** (`docId`) | `string` | да | да | Идентичность документа |
| **ID коллекции** (`collectionId`) | `string` | да | да | Коллекция |
| **Источник** (`source`) | `string` | да | нет | Источник |
| **Наблюдено** (`observedAt`) | `string` | да | нет | ISO-время наблюдения |
| **Существующие** (`existing`) | `textarea` | да | нет | Доп. Evidence для дедупа (мержится с store) |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Evidence** (`evidence`) | `textarea` | Evidence S0 |
| **Дубликат** (`duplicate`) | `boolean` | true, если хеш уже был |
