# RAG: спроецировать S3

Вход: затронутые id S2/S0. Выход: счётчики проекции. Сбой проекции не откатывает S2.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **ID** (`affectedIds`) | `textarea` | да | да | Затронутые id |
| **Проекция** (`projection`) | `select` | static | нет | embeddings \| neighborhood \| all |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Проекция** (`projection`) | `string` | Вид проекции |
| **Запрошено** (`requested`) | `number` | Запрошено |
| **Спроецировано** (`projected`) | `number` | Спроецировано |
| **Пропущено** (`skipped`) | `number` | Пропущено |
| **Успех** (`ok`) | `boolean` | false при сбое адаптера |
| **Ошибка** (`error`) | `string` | Текст ошибки |
