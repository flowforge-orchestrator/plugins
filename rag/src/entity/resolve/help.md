# RAG: разрешить сущности

Склеивает упоминания в канонические сущности и перепривязывает по дельте.

## Зачем

Одинаковые упоминания сходятся в канонические сущности графа.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Упоминания** (`mentions`) | `textarea` | да | да | Упоминания |
| **Дельта схемы** (`delta`) | `textarea` | да | нет | Дельта схемы |
| **ID коллекции** (`collectionId`) | `string` | да | да | ID коллекции |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Сущности** (`entities`) | `textarea` | Сущности |
| **Склеено** (`merged`) | `number` | Склеено |
| **Создано** (`created`) | `number` | Создано |
| **Перепривязано** (`rebound`) | `number` | Перепривязано |
