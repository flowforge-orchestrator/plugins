# RAG: разрешить сущности

Склеивает упоминания в канонические сущности и отдаёт `EntityDecision` (`match` | `new` | `ambiguous`).

## Зачем

Одинаковые упоминания сходятся в канонические сущности графа; неоднозначные остаются портом решения.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Упоминания** (`mentions`) | `textarea` | да | да | Упоминания |
| **Дельта схемы** (`delta`) | `textarea` | да | нет | Дельта схемы |
| **ID коллекции** (`collectionId`) | `string` | да | да | ID коллекции |
| **Порог неоднозначности** (`ambiguityThreshold`) | `number` | static | нет | Минимальный зазор score до второго кандидата |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Сущности** (`entities`) | `textarea` | Сущности |
| **Решения** (`decisions`) | `textarea` | EntityDecision по каждому упоминанию |
| **Склеено** (`merged`) | `number` | Склеено |
| **Создано** (`created`) | `number` | Создано |
| **Перепривязано** (`rebound`) | `number` | Перепривязано |
