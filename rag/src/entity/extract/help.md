# RAG: извлечь упоминания

Извлекает упоминания сущностей в закрытую схему.

## Зачем

Упоминания в тексте привязываются к закрытой схеме типов.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Чанки** (`chunks`) | `textarea` | да | да | Чанки |
| **Схема** (`schema`) | `textarea` | да | да | Схема |
| **ID коллекции** (`collectionId`) | `string` | да | да | ID коллекции |
| **ID документа** (`docId`) | `string` | да | нет | ID документа |
| **API ключ LLM** (`apiKey`) | `ref` | static | да | API ключ LLM |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Упоминания** (`mentions`) | `textarea` | Упоминания |
| **Вне схемы** (`outOfSchemaShare`) | `number` | Вне схемы |

## Ошибки

Модель вернула невалидный JSON сущностей.
