# RAG: извлечь связи

Per-chunk SPO: Subject / Predicate / Object по каждому leaf. Predicate мапится в `relationTypeId` через словарь синонимов; иначе тройка отбрасывается, если typeId не из схемы.

## Зачем

Связи между сущностями дают обход графа при ответах; SPO покрывает действия, а не только заранее угаданный семпл.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Сущности** (`entities`) | `textarea` | да | да | Сущности |
| **Чанки** (`chunks`) | `textarea` | да | да | Чанки |
| **Схема** (`schema`) | `textarea` | да | да | Схема |
| **ID коллекции** (`collectionId`) | `string` | да | да | ID коллекции |
| **API ключ LLM** (`apiKey`) | `ref` | static | да | API ключ LLM |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Связи** (`relations`) | `textarea` | Связи |
| **Без доказательства** (`withoutEvidenceShare`) | `number` | Без доказательства |

## Ошибки

Модель вернула невалидный JSON связей.
