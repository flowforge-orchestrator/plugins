# RAG: проверка claims

Код, без модели. На вход `observations.researchClaims` и `observations.evidence`.

- `supported` — утверждение копирует evidence: фрагмент лежит внутри записи, вычисленный факт копирует запись с существующими родителями. Claims приходят только из предложений, принятых проверкой фрагмента и критиком.
- Гипотеза не становится `supported`.
- Два разных значения одного факта в одной локации — оба `contradicted`.
- Незакрытый слот `requiredInformation` — пробел `missing_slot`. Ход может сдать слот через `task.unresolvedQuestions`, и тогда слот считается закрытым как неизвестный.

Текст ответа не меняется. Ограничения пишутся в `observations.limitations`.
