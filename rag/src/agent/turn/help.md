# RAG: ход агента

Называет одну операцию `op`. Узлы схемы выполняют её сами: ход никого не вызывает.

- `direct` и `retrieval` не зовут модель. `retrieval` запрашивает следующее незакрытое поле контракта. Поле, которое уже спрашивали и на котором нет принятого claim, ход записывает в `unresolvedQuestions` и ставит `op=none`. Сдаёт поле только ход: не поиск, не предложение значения и не критик.
- `analysis` и `research` зовут модель, только если очередь пуста. Остальные операции из ответа ждут в `queue` и исполняются на следующих итерациях цикла.
- `args` — параметры операции (`op`, `leftId`, `rightId` для вычисления).

Режим приходит портом `mode` или из `observations.task`. Список допустимых `op` — карточки, подключённые к роутеру. Порт `enabled` держит узел, пока ветка switch не запишет значение.
