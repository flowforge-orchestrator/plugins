# RAG: роутер инструментов

Собирает карточки провайдеров во вход tools хода агента.

## Зачем

Ход видит один список инструментов; карточки провайдеров собираются здесь.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Карточки провайдеров** (`providers`) | `textarea` | да | нет | Любые порты с JSON-карточками от provider.* |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Tools** (`tools`) | `textarea` | Массив карточек инструментов для хода агента |
