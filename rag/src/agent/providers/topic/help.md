# RAG: провайдер рамки вопроса

Карточка рамки вопроса. Сообщение приходит в вызов из хода.

## Зачем

Карточка объявляет рамку вопроса как доступный инструмент хода.

## Параметры

Входных полей нет.

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Карточка** (`tool`) | `textarea` | Карточка |
