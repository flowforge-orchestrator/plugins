# RAG: провайдер графа

Карточка обхода графа. ID коллекции задаётся здесь.

## Зачем

Карточка объявляет обход графа как доступный инструмент хода.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **ID коллекции** (`collectionId`) | `string` | да | да | ID коллекции |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Карточка** (`tool`) | `textarea` | Карточка |
