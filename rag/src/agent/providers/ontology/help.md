# RAG: провайдер онтологии

Карточка lookup онтологии. ID коллекции задаётся здесь.

## Зачем

Карточка объявляет lookup онтологии как доступный инструмент хода.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **ID коллекции** (`collectionId`) | `string` | да | да | ID коллекции |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Карточка** (`tool`) | `textarea` | Карточка |
