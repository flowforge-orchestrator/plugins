# RAG: провайдер поиска

Карточка гибридного поиска. ID коллекции и topK задаются здесь.

## Зачем

Карточка объявляет поиск как доступный инструмент хода.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **ID коллекции** (`collectionId`) | `string` | да | да | ID коллекции |
| **topK** (`topK`) | `number` | static | нет | topK |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Карточка** (`tool`) | `textarea` | Карточка |
