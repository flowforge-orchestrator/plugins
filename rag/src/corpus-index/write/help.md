# RAG: записать индекс

Пишет чанки в векторный индекс и сущности/связи в граф знаний.

## Зачем

Чанки и сущности должны попасть в Qdrant и Neo4j плагина.

## Параметры

| Поле | Тип | Порт | Обязательно | Описание |
| --- | --- | --- | --- | --- |
| **Чанки** (`chunks`) | `textarea` | да | да | Чанки |
| **Сущности** (`entities`) | `textarea` | да | да | Сущности |
| **Связи** (`relations`) | `textarea` | да | да | Связи |
| **Схема** (`schema`) | `textarea` | да | да | Схема |
| **ID коллекции** (`collectionId`) | `string` | да | да | ID коллекции |
| **ID документа** (`docId`) | `string` | да | да | ID документа |
| **API ключ эмбеддингов** (`embeddingApiKey`) | `ref` | static | да | API ключ эмбеддингов |

## Выходы

| Поле | Тип | Описание |
| --- | --- | --- |
| **Записано векторов** (`vectorsWritten`) | `number` | Записано векторов |
| **Обновлено векторов** (`vectorsUpdated`) | `number` | Обновлено векторов |
| **Удалено сирот** (`orphansRemoved`) | `number` | Удалено сирот |
| **Сущностей в графе** (`entitiesWritten`) | `number` | Сущностей в графе |
| **Связей в графе** (`relationsWritten`) | `number` | Связей в графе |
| **Версия схемы** (`schemaVersion`) | `number` | Версия схемы |
| **Модель эмбеддинга** (`embeddingModel`) | `string` | Модель эмбеддинга |

## Ошибки

Недоступны Qdrant/Neo4j; ошибка эмбеддинга.
