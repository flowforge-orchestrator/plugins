# Telegram: список чатов

Чаты, которые уже попали в локальную историю. У Bot API отдельного списка чатов нет: здесь только то, что бот записал.

## Параметры

- **Chat ID**, **From ID**, **Тип чата** — равенство
- **Название содержит** — подстрока названия
- **С** / **По** — сообщения в этом диапазоне дат
- **Offset**, **Limit** — страница, limit 1–100, по умолчанию 20

## Выходы

- **chats** — `chatId`, `chatType`, `chatTitle`, `lastDate`, `messageCount`
- **total**, **offset**, **limit**

Сортировка — по дате последнего сообщения, новые сверху.
