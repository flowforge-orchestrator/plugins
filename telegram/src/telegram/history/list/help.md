# Telegram: список сообщений

Страница локальной истории. Пустой фильтр возвращает все записи.

## Параметры

Равенство, если порт заполнен: **Chat ID**, **Message ID**, **From ID**, **Username**, **Имя**, **Направление** (`in`/`out`), **Тип**, **Thread ID**, **Тип чата**, **Название чата**, **Reply message ID**, **Update ID**, **Текст**.

- **Текст содержит** — подстрока
- **С** / **По** — unix-секунды, границы включены
- **Offset** — сколько записей пропустить, по умолчанию 0
- **Limit** — 1–100, по умолчанию 20
- **Порядок** — `newest` (по умолчанию) или `oldest`

## Выходы

- **messages** — массив записей (`id`, `chatId`, `messageId`, `text`, `fromId`, `date`, …)
- **total** — сколько записей подходит под фильтр
- **offset**, **limit** — страница, которая вернулась

## Ошибки

Направление не `in`/`out` или порядок не `newest`/`oldest` роняет шаг.
