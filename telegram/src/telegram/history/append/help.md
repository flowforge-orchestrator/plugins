# Telegram: записать историю

Пишет одно сообщение в локальную историю бота (SQLite, `TELEGRAM_HISTORY_PATH`). Токен бота не нужен.

## Параметры

- **Chat ID** — обязательный
- **Направление** — `in` или `out`
- **Message ID**, **Update ID**, **тип**, **текст**, отправитель (`From ID`, username, имя), **Thread ID**, ответ (`Reply message ID`, `Reply text`), тип и название чата, **дата** (unix-секунды) — по наличию в апдейте

Повторный `update_id` возвращает уже существующую строку.

## Выходы

- **id** — ключ строки
- **chatId**, **messageId**
- **created** — `false`, если это повтор того же update

## Ошибки

Пустой chat id или направление не `in`/`out` роняет шаг.
