# Redmine: список задач

Получает список issues из Redmine с фильтрацией по проекту, статусу, исполнителю и другим параметрам.

## Параметры

- **Base URL** — адрес Redmine (например: `https://redmine.example.com`)
- **API ключ** — X-Redmine-API-Key (используйте ref на секрет)
- **ID проекта** — фильтр по `project_id`
- **ID статуса** — `open`, `closed`, `*` или число
- **Исполнитель** — `assigned_to_id` или `me` для текущего пользователя
- **Limit** — число записей (по умолчанию 25, макс 100)
- **Offset** — смещение для пагинации
- **Include** — связанные данные: `attachments`, `relations`
- **Sort** — сортировка, например: `updated_on:desc`

## Выходы

- **issues** — массив задач
- **totalCount** — общее количество
- **status** — `ok` или описание ошибки
