# Redmine: обновить wiki-страницу

Создаёт или обновляет wiki-страницу проекта.

## Параметры

- **Base URL** — адрес Redmine
- **API ключ** — X-Redmine-API-Key (ref)
- **Проект** — ID или identifier проекта
- **Страница** — имя wiki-страницы
- **Текст** — содержимое страницы (обязательно)
- **Comments** — комментарий к изменениям
- **Version** — версия для optimistic locking (409 при конфликте)

## Выходы

- **wikiPage** — обновлённая страница
- **status** — ok, created или описание ошибки
